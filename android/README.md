# Lire для Android

Android 8.0 и новее. Пока приложение не опубликовано в Google Play, его ставят из файла APK.

## Установка

1. Откройте на телефоне [страницу релиза](https://github.com/antonvolgin/lire-releases/releases/tag/android-v0.1.0-rc.15)
   и скачайте `Lire-0.1.0-rc.15.apk` (около 4 МБ).
2. Откройте скачанный файл. Android попросит разрешить установку из этого источника (браузера или «Файлов») —
   разрешите и вернитесь назад.
3. «Установить». Google Play Защита может предупредить о неизвестном разработчике — «Всё равно установить».
4. Откройте Lire. Войти — с адресом из приглашения: на почту придёт код из 6 цифр. Публичные главы читаются и без входа.

## Важно

- Это **кандидат в релиз** для проверки. Сборка подписана ключом загрузки Lire. Когда приложение появится в
  Google Play (закрытое тестирование), его подпишет Google другим ключом: эту версию нужно будет **удалить** перед
  установкой из Google Play. Место чтения сохранено на сайте, если вы входили, — оно не потеряется.
- Обновления из этого файла сами не приходят: новую версию скачивают отсюда же.
