# Lire — сборки для загрузки

Lire — французские книги, прочитанные вслух, с текстом, который идёт за чтением фраза за фразой
(https://lire.savoirvideo.fr). Здесь публикуются готовые сборки приложения; исходный код живёт в отдельном
приватном репозитории.

|---|---|---|
| [Android](android/) | 0.1.0-rc.7 (кандидат в релиз) | [страница релиза](https://github.com/antonvolgin/lire-releases/releases/tag/android-v0.1.0-rc.7) |
| iPhone | — | через TestFlight, ссылка появится позже |

## Как это устроено

- **Бинарники — только в релизах**, в файлы репозитория они не коммитятся.
- **Каталог платформы** содержит инструкцию и `latest.json` — версию, адрес и контрольную сумму последней сборки.
- **Релизы именуются по платформе**: `android-v0.1.0-rc.7`. Кандидаты в релиз (`-rc.N`) помечены как pre-release.

## Про «Source code» в релизах

GitHub сам добавляет к каждому релизу ссылки «Source code (zip / tar.gz)» — в них только содержимое этой витрины
(README и `latest.json`). Исходного кода приложения здесь нет.

## Проверка целостности

Сумма SHA-256 каждой сборки — в описании релиза и в `latest.json`. Проверить скачанный файл на Mac или Linux:

```
shasum -a 256 Lire-0.1.0-rc.7.apk
```
